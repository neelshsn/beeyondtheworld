# Shared comparator review

`/community/comparator#view/production/creative-lock` preserves the existing Carry the light gallery: 498 screenshots, twelve role guides and the AI asset pack. Screen captures are WebP at their original dimensions. The large all-PDF zip is replaced by the twelve individual original PDFs. This is a screen review tool; the functional rehearsal remains at `/community/test`.

Feedback is keyed by role, screen and reviewer. The two reviewer names are **Eugénie** and **Rachid**. Personal bearer links open the same gallery, set an HttpOnly cookie and redirect to a clean URL. Each link can write only its own feedback and images; both can read both contributions. No email, account password or production-role impersonation is involved. The initial links expire after 180 days and can be revoked in `bee_review_access`. Treat them as private invitation links.

Apply `drizzle/0013-comparator-feedback.sql` to the VPS database as the database owner, then grant the application role SELECT/INSERT/UPDATE/DELETE on its three new tables. Production records are unaffected. Provision random 32-byte tokens, store only SHA-256 digests in `bee_review_access`, and deliver the tokens outside Git. No tokens or environment configuration belong in this repository.

Text is explicitly saved and versioned; stale saves return 409. Refresh shows the saved version alongside a retained local draft for manual merging. Drafts are stored in the reviewer's browser until saved. Images are uploaded one at a time from a multi-file selection, optimized in the browser, decoded/re-encoded and stripped of metadata by the server, then stored in VPS PostgreSQL. Limits: 15,000 text characters, 20 active images per reviewer/screen, 3 MiB after optimization. Image removal is soft deletion. Attachments require review access, are not publicly cached and cannot execute SVG/HTML.

QA covers anonymous access, author attribution, two reviewers, cross-role/screen isolation, optimistic concurrency, CSRF, invalid image rejection, multiple image persistence and ownership checks. Check the rendered desktop/mobile interfaces and verify the deployed alias after publication. `src/lib/review/gallery.json` is the preserved local gallery with online paths and review hooks; `public/review/feedback.js` and `.css` are its interactive addition. Original source: the workspace's `outputs/beeyond-cas-concret-maroc/index.html`; that file is intentionally left untouched.
